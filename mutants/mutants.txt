# Mutations mutants/gen.py builds into the mutant schemata, run by src/fuzz.c.
# Each is a bug that shows only for a handful of values, so killing it proves
# the corpus reaches those values and a transcript records the result. The
# schemata is built twice, as the int128 and the int64 code, so a mutant in
# either implementation runs.
#
# A record is "FILE FUNCTION" at the start of a line, then the original and the
# mutated expression on indented lines. The original must appear exactly once
# in FUNCTION's body. An optional first indented line is an anchor, text that
# appears once there: the original is then looked for only after it. Mutate
# compares and constants, never a loop bound or a check that keeps a copy in
# bounds, so no mutant can hang or fault.
#
# Keep the mutated expression equal to the original everywhere but at the rare
# values: an input where they differ runs the mutant, so a mutant that differs
# on most inputs costs a run on each of them until one kills it.

# set_b32_limit rejects x >= p: the planted bug, which accepts x = p.
src/field_5x52_impl.h secp256k1_fe_impl_set_b32_limit
    (r->n[0] >= 0xFFFFEFFFFFC2FULL)
    (r->n[0] > 0xFFFFEFFFFFC2FULL)

# A limb left out of the same check: x in [p, 2^256) with limb 1 not all ones.

    ((r->n[3] & r->n[2]) == 0xFFFFFFFFFFFFFULL)
